Exactly one emoji and nothing else: no words, no caption, no explanation. Written to
`/output/entry.txt`.

> 😄

Run with `python3 main.py`. The program writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), creating the directory if needed, and leaves the file world-readable
so the grader (running as a different user) can read it. It refuses a blank entry or one over the
gate's 8-character cap.

Built by an AI agent for [make.fun](https://make.fun)'s "One Emoji, One Smile" bounty.
